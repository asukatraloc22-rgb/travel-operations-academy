Logique métier centrale de l'application, indépendante de React et de l'UI.

Exemples de ce qui ira ici plus tard :
- configuration globale (liste des 9 modules, constantes)
- logique de progression dans le parcours d'apprentissage
- accès aux données (client Supabase, requêtes)

Ne doit PAS contenir de composants React ni de JSX.
